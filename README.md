# بوت واتساب: مانجا ← PDF

يبحث عن المانجا، يجلب صور الفصل (jpg / png / **webp**)، يجمعها في ملف PDF ويرسله لك.

## التثبيت على Termux

```bash
pkg update && pkg upgrade
pkg install nodejs-lts git imagemagick unzip
cd wa-manga-pdf-bot
npm install
node index.js
```

- `imagemagick` مطلوب لتحويل صور webp/gif/avif إلى JPEG قبل وضعها في الـ PDF.
- عند أول تشغيل يظهر **كود ربط** في الشاشة. في واتساب: الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف، ثم أدخل الكود.
- رقم الربط في `config.js` (`botNumber`)، أو شغّل: `BOT_NUMBER=2126xxxxxxx node index.js`

## المصدر (الشيء الوحيد المطلوب منك)

افتح `sources/mySource.js` وأكمل ثلاث دوال:

| الدالة | ترجع |
|---|---|
| `search(query)` | `[{ id, title }]` |
| `getChapters(manga)` | `[{ id, number, title }]` من الأقدم للأحدث |
| `getPages(chapter, manga)` | `['https://.../1.webp', ...]` بالترتيب |

إن كان الموقع يشترط Referer للصور ضعه في `headers` داخل الملف نفسه.
أدوات جاهزة: `getText` و`getJson` و`getBuffer` من `lib/http.js`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `.بحث <اسم>` | بحث عن مانجا |
| `.مانجا <رقم>` | اختيار نتيجة وعرض فصولها |
| `.فصول [صفحة]` | عرض قائمة الفصول |
| `.فصل 12` / `.فصل 5-8` / `.فصل اخر` / `.فصل #3` | تحميل وإرسال PDF |

## ملاحظات

- الفصول الطويلة (أكثر من 80 صفحة) تُقسَّم تلقائياً لعدة ملفات، والرقم في `config.js`.
- طلب واحد يُنفَّذ في كل مرة (طابور) حتى لا يُثقل الهاتف.
- لتغيير مكتبة واتساب مستقبلاً: كل ما يخصها في `index.js` فقط.
- لا تشارك مجلد `auth` مع أحد، فهو يحوي جلسة حسابك.
